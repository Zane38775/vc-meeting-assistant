## 资料整理
沿用公开技术词查询及搜索返回内容，原来源先保存和展示。异步生成最多三条中文技术要点、查询相关性和限制/待核实点，每条必须有真实来源 ID 和原摘要逐字引文。明确写“基于检索摘要，未阅读全文”，不把摘要补全成无依据事实。失败保留来源与错误状态，允许继续会议。按查询持久化资料卡；同 URL 来源聚合显示，原始引用 ID 保留。旧记录无资料卡也能读取。

方案取舍：仅显示原链接不满足用户；自动抓取任意全文引入下载、解析和延迟问题。本次先做有可核验依据的摘要整理，全文阅读留待独立需求。

## 追问判断
当前每个定稿快速触发至多三个问题造成重复刷屏。改为持续接收转写、积累新增上下文，按节奏分析，但每轮最多展示一个有重要性、时机和逐字依据的问题；无重要缺口时输出空数组。关注商业假设、客户/收入证据、单位经济模型、技术壁垒、风险与下一步验证，不机械套用指标清单。参考已问问题和当前回答，抑制同证据同议题换措辞重复；对于明显 ASR 含糊，不以其为事实前提生成质疑。保留问题依据和手动记录。

方案取舍：只降低请求频率仍会出现低价值问题；每句话都用大模型增加成本且不提高判断。本次同时改变触发节奏、候选筛选和重复过滤，保持字幕独立。
