# 会中判断与资料整理实现计划

**Goal:** 会中少量、依据充分的 VC 追问与可读的中文技术资料卡。
**Architecture:** 保持现有本地 ASR、LiveHub、DeepSeek 与 SQLite records；分析、检索、资料整理异步运行并分别反馈状态。兼容已有记录。
**Tech Stack:** TypeScript、React、Fastify、SQLite、Electron。
**Spec:** ../specs/2026-11-16-meeting-intelligence-design.md

## 约束与复核重点
- 仅 DeepSeek 密钥；密钥不进入客户端、测试日志或 Git。
- 资料条目必须核验来源 ID 与搜索摘要逐字引文；链接/旧数据保留。
- 删除会议/项目与取消请求后不得复活数据。
- 整理失败不能阻塞字幕或掩盖已有来源。
- 重启不重复生成相同查询；同 URL 合并展示不破坏引用。
- 暂停/结束末轮必须等尾段定稿，但不能让 AI 阻塞音频收尾。
- 短发言积累、多条快速发言、已问议题改写以及无有价值问题时均要覆盖。
