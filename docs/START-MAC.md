# 知投会议助手 · Apple 芯片 Mac 测试版

适用 M1/M2/M3/M4/M5 等 Apple 芯片，macOS 14.2 或以上。已内置约 57 MiB 的中英文实时语音模型；不需要安装 Node.js、Python 或申请语音云服务。

1. 解压 ZIP，保留 `VC Meeting Assistant.app` 和 `Install-on-Mac.command` 在同一文件夹。
2. 双击 `Install-on-Mac.command`。它会将应用安装至你个人的 `Applications` 文件夹，并在当前 Mac 上重新创建本机签名。安装脚本与应用尚未经过 Mac 实机验收。如果脚本被系统阻止，可先在终端审阅后用 `bash` 运行该脚本；不需要关闭系统安全保护。
3. 首次打开应用时，macOS 可能提示无法验证开发者。本包没有 Apple Developer ID 签名或公证，请先确认来源；若决定运行，按系统的“隐私与安全性”提示审核并允许。
4. 打开应用，创建本机账号。在左下角「服务设置」填入自己的 DeepSeek API 密钥。不要把包含密钥的配置文件发给别人。
5. 新建项目 → 上传 BP → 创建会议。线下采集麦克风；线上同时采集麦克风和系统声音。点击「开始采集」才会请求权限。线上建议佩戴耳机，避免双重收音。
6. 不填 DeepSeek 密钥也能使用本地实时转写。追问、联网技术资料、AI 摘要和纪要需要 DeepSeek。先用「演示体验」也能查看界面流程，但演示不是识别实测。

本地模型目前不自动分离说话人，可手工修改；扫描 BP/图表需要人工补录。默认不保存原始音频。字幕和材料保存在本机；启用 DeepSeek 分析时，相关文字和材料会发给 DeepSeek。

当前单机包的邀请链接只在本机可用。要给异地合伙人同步，需要另外配置共享服务；现在可以导出 Markdown 纪要发送。

实时验证：Windows 开发机使用公开 WAV 按实时节奏送入模型，首条字幕约 1.2–1.4 秒；通过完整浏览器采集链路约 1.3 秒。这不是 Mac 实测，也不是准确率承诺。Mac 权限、真实线上会议声音和长会稳定性仍待验证。
