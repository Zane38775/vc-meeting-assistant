# 开发与验收进度 · 2026-11-17

公开 Release 仍为 v0.1.0，main 基线为 `4d7d11f`。本轮在 PR #1 的 `codex/mac-device-validation` 分支开发 `0.1.2-beta.1`。使用者目前无法参与，真人收音、腾讯会议双向和 60 分钟实会验收顺延；本文不把模型样例、CI 或空闲运行时间计为设备验收通过。

## 本轮改动

- 新包默认采用 X-ASR 480 ms 流式中英模型，仍在本地 CPU Worker 运行。固定归档、运行文件与配套 BPE 词表的 SHA-256，附带来源和许可。旧安装只有 Zipformer Small 时继续使用旧模型，可显式回退；选定新模型后加载失败明确报错。[候选比较](ASR-MODEL-EVALUATION-2026-11-17.md)
- BP 上传后并行生成摘要/术语与项目级会前研判。旧项目可主动生成。概述覆盖八类字段；有依据时展示公司、产品、客户、客户问题、技术路线、商业模式、指标和融资信息。独立展示四类待验证假设与缺口、至多五个优先问题，以及问题影响的判断和希望取得的证据。
- 每项引文核对材料 ID、页码及逐字文本。概述数字必须在相应引文中出现；此校验不能证明归纳语义完全正确，界面标为 AI 归纳、未独立核实。未提取到依据不等于公司未提供。文字可能经过人工修订，故称“资料页引文”。
- 研判采用有界文字输入：全项目最多 48,000 字符、120 页、每页 1,500 字符，跨文件轮流取页，并显示已用页数和节选提示。不读取扫描图表。资料更新使研判失效，失败重试保留此前有效结果。
- 会中分析接收当前有效研判；已回答的问题不应重复提出。材料或研判在分析请求期间更新时，丢弃旧草案，不发布旧追问或发起相关检索。普通评论不会让草案失效。
- 历史追问仍保存原引文；材料页改写后不再把旧引文链接到无对应原文的页，显示历史引用提示。
